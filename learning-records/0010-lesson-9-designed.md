## 本课要回答的问题（承第 8 课钩子）

第 8 课末尾立了两个悬案，本课必须用数字结清：

1. **阈值该设在哪儿？** 用户在 0001 里给检索加了 `MIN_SCORE = 0.6`——当时没有依据，是拍的。本课给出标准做法：算【正样本】（答案块的最高分）与【负样本】（噪音天花板）两条分布，看重叠区，再按场景取舍。
2. **追问「那二线城市呢」要不要改写？** 第 8 课教师预言"会被阈值误杀"**未发生**（模型自发改写救回 0.430→0.827），于是问题变成"模型改不改写不稳，工程上怎么办"。本课用尺子量出改写值多少、并确认它必须被做成**显式的一步**。

再往上抽一层，本课要立的工程习惯是：**没有尺子，你能看到"变化"，看不到"改进"。**

## 本课一句话核心（教学定调）

**评估（eval）= 一份自己标注的评估集（题 + 每题应命中的块 gold） + 几个客观指标（Hit@1 / Hit@k / Recall@k / MRR）。**
有了它，"感觉变好了"被翻译成"Hit@1 从 0.73 涨到 0.91"，调参才从玄学变成工程。RAG 的检索环节只有四颗旋钮（**检索器选型 / 融合权重 / 分数阈值 / top_k**），而每一颗都得靠同一把尺子来量——且**一次只动一颗**。

## 心智模型（教给用户的分层）

- **Hit vs Recall 会分家**：答案横跨 3 块只捞到 1 块 → Hit@3 满分、Recall@3 = 0.33。只看 Hit 会以为自己挺好，其实模型每次都在半块材料上作答。
- **MRR 比 Hit 敏感**：它关心"排多靠前"，"答案从第 1 掉到第 3"这种退化只有它看得出来。
- **题集是资产、要评审、要长**：从语料**反向**出题（先想该命中哪块，再写问句）；覆盖三类问法（术语型 / 口语换说法型 / 追问型）；**指标异常先怀疑题**（本课真实踩中，见下）；线上每被问住一次就补一道题 = 回归测试集。
- **混合检索用 RRF 而不是加权分数**：只吃**名次**、不吃分数 → 名次无量纲 → 第 8 课那条"量纲不可跨路搬运"被顺手绕过去。**但合流治"漏"不治"排第一"**：RRF 会把某一路的错答案一起顶上来（本课实测两例）。
- **阈值不是常数，是数据分布的一次快照**：分布分得开 → 空隙里随便挑；分布重叠 → 阈值必然两头不讨好，此时该做的是**提升检索质量**（合流 / rerank / 换 embed），而不是继续试数字。且**不能跨路、不能跨语料搬运**。
- **query 自足性**：不自足的查询（"那另外那部分呢"）脱离上文没有主题，向量压根不在目标语义邻域里。改写必须是**显式的一步**（system 里明确要求 query 自足，或专门做改写环节）——别赌模型自己发生。
- **尺子的分辨率**：22 题上名次差一名 = 4.5%，"0.91 vs 0.95"只差一道题，**不足以**下结论。读指标先问"这个差距比噪音大吗"。评估集自己也会被调参过拟合 → 留一批题不参与调参、只做验收。

## 实验设计（code/0009-eval-lab.py）

语料 = 同一份虚构《云杉科技员工手册》，**从 8 块扩到 30 块**（前 8 块原文一字未动 → 用户 0001 里挂的 `search_manual` 仍对得上；新增 22 块刻意埋进**易混对**：年假 C01 / 病假 C09 / 调休 C10，出差住宿 C02 / 出差餐补 C13 / 出差交通 C14，数据分级 C22 / 数据出境 C23，API 限流 C05 / 加班夜间打车 C12……）。评估集 **22 题**，每题标 gold（其中 2 题多 gold，让 Recall 与 Hit 分家）。四路检索器：`关键词(2-gram 重合)` / `语义(bge 余弦)` / `混合(RRF)` / `混合·语义×2(RRF 加权)`。

- **镜 1 · ★ 先有尺子**：四路一起上秤 → 逐题 top-1 判定 + 汇总指标表 + **只看分歧的题**（教学点：评估集里真正推动决策的是分歧题，各路一致的题对选型没有信息量）。
- **镜 2 · ★ 阈值不是拍脑袋**：算正/负样本两条分布 → 判定分不分得开 → 给候选阈值的「误杀 / 漏放」表。**同一条流程对余弦路和关键词路各跑一遍**（再实锤"量纲不可跨路搬运"）。
- **镜 3 · ★ query 自不自足**：5 道追问 × 三栏对照（A 原话 / B **真调 flash 改写**、原样打印 / C 人工自足版）→ 量出"改写救回多少"。
- **镜 4 · ★ top_k 扫描**：k = 1,2,3,4,5,8 的 Hit@k / Recall@k / MRR@5 + 平均注入 token，末尾补「全量塞 30 块」作第 8 课那面镜子的对照。

## 挑战（用户动手）

- **挑战 A（必做）· 亲手给尺子加刻度**：① 加 5 道自己的题（照易混对出，用员工真会说的话，标 gold）重跑，观察四路指标怎么动、新题有几道落进"分歧"节；② **删掉 C12 再跑**，观察哪些题 top-1 变了、**镜 2 的"噪音天花板"有没有跟着变**（这条最能解释阈值为何随语料失效）；③ **加一路"只看块标题匹配"的检索器**进 `RETRIEVERS`，看它拿多少分、为什么"标题就够用"的直觉不成立。口答：① 加题后四路指标**都下降**，能否说明"检索器变差了"？② 举一个"加题后才发现的问题"，说清"评估集决定你能看见什么"。
- **挑战 B（加分）· 用尺子回头调 0001 的 search_manual**：① 按镜 2 的办法给 0001 的检索侧标定 `MIN_SCORE`（正样本用 22 题 gold；负样本**额外补几道"手册里根本没有"的问题**，如年会抽奖/团建经费，注意避开上一课用过的"下午茶"）；② 把 30 块语料搬进 0001（前 8 块一致，安全），重跑上一课自检题，观察块数变化后同一题的 top-1 分数与阈值是否还成立；③ **加一步查询改写**（抄镜 3 的 `SYS_REWRITE` + `rewrite_query`），在 REPL 里实测"住院能报多少？→ 那门诊那部分呢？"，打印改写前后的 query 并自检命中。交付物：定下的 `MIN_SCORE` + 理由（哪两条分布、重叠区、为什么这么偏）+ 改写的"救回/弄丢"实测。

## 潜在误区（预判要盯）

- **把"评估"理解成"让模型自评"或"看着答案感觉还行"** → 评估是**你自己标的 gold + 客观指标**，机器判分、可复现；模型自评是另一回事（且不稳）。
- **以为指标下降 = 检索器变差** → 指标是**被题集定义**的：加了一批更难的题，指标必然掉，那是尺子变细了。
- **抄别人项目的阈值** → 必须按自己数据的正/负样本分布标定；甚至自己的语料从 8 块扩到 30 块，那个数就失效（本课实测）。
- **以为"混合 = 全面更强"** → RRF 会把单路的错答案顶上来；收益在 Hit@k / Recall@k，不在 Hit@1。
- **只看一个指标** → Hit 满分而 Recall 0.33 是最典型的自我感觉良好。
- **赌模型自发改写追问** → 必须显式做（system 要求自足 / 专门的改写环节），并用同一把尺子验收（改写也可能**弄丢**原本能命中的查询）。
- **命中 = 改写正确** → 本课实测有一句改写把意思理解偏了，只因主题词还在就照样捞对；改写质量仍要人看。
- **k 越大越好 / 越小越省** → 看曲线拐点（本课数据 k=3 之后指标全平、token 涨到 8 倍）。

## 厂商对照 / 原典钩子

- **评估这一环是跨厂商的通用工程能力**，与 M6 的 evals 是同一件事的前半段：本课量的是**检索那一端**（Hit@k / Recall@k / MRR），带 faithfulness / answer relevancy 的**生成那一端**要另起一套（M6 正题）。Ragas 等框架的指标清单恰好就是这么分的。
- 概念对应（面试能用）：Hit@k / Recall@k / MRR / nDCG 是信息检索几十年的通用指标（BEIR 这类学术基准也用它），**不随向量库换代**；RRF 是混合检索的默认融合法（Elasticsearch / Weaviate / Qdrant 等均有实现）。
- 原典：Anthropic《Introducing Contextual Retrieval》（本课镜 1 题 02 是它"embedding 会漏精确串 → 需与 BM25 双轨合流"的现场证据）；Anthropic《Effective context engineering for AI agents》（补最后一层："怎么知道你的上下文策略是对的"）；Ragas 官方文档（工业界 RAG 评估的指标清单）；延伸：Anthropic 官方文档 Test & evaluate 一节、OpenAI evals 指南、BEIR 检索基准。

## 教师预跑取证（2026-09-10，DeepSeek v4-flash / Anthropic 兼容端点，code/0009 已预跑四镜全绿）

- **环境**：本地 bge-small-zh-v1.5（ONNX CPU），30 块 × 512 维索引即建即用；仅镜 3 的 5 次改写 + 镜 4 的 token 计数走付费端点，总花费几分钱。
- **镜 1 · 四路指标（22 题，确定性）**：

  | 检索器 | Hit@1 | Hit@3 | Recall@3 | MRR@5 |
  |---|---|---|---|---|
  | 关键词 keyword | 0.73 | 1.00 | 0.98 | 0.86 |
  | 语义 semantic | 0.91 | 0.95 | 0.95 | 0.94 |
  | 混合 hybrid (RRF) | 0.91 | **1.00** | **1.00** | 0.95 |
  | 混合·语义×2 | **0.95** | **1.00** | **1.00** | **0.98** |

  - **decive 案例 02「RTO 是多少」→ gold C21**：关键词 top-1 = C06（C21 排第 2）、**语义 top-3 = C05/C19/C27（连 C21 都没进）**、混合 ✅C21 第 1。→ 精确串（RTO）是 embedding 的盲区、字面路的主场，合流把它救回——正是 Contextual Retrieval 那条论点的现场版。
  - **反向案例（诚实）15「代码要几个人 approve」→ C19**：语义 ✅C19，混合 ❌C20（RRF 把关键词的错答案顶上来）；20「供应商货款」→ C30 同样。→ **合流治漏不治排第一**，故混合 Hit@1 与语义持平、但在 Hit@3/Recall@3 全胜。
  - 22 题中 8 道出现"各路分歧"，其余 14 道四路一致（对选型无信息量）。
- **镜 2 · 阈值标定（决定性，回答第 8 课悬案）**：
  - **余弦路**：正样本 0.819（最高）… 0.644（中位）… 0.424（最低）；负样本 0.647（最高）… 0.561（中位）… 0.362（最低）→ **两条分布重叠区 [0.424, 0.647]**。
    - 阈值 0.70 → 误杀 17 (77%) / 漏放 0；**0.60（上一课那个值）→ 误杀 7 (32%) / 漏放 3 (14%)**；0.50 → 误杀 2 (9%) / 漏放 20 (91%)；0.45 → 误杀 1 (5%) / 漏放 21 (95%)。
    - **这就是"0.6 凭什么"的答案**：它是在第 8 课 8 块语料上拍的；语料扩到 30 块后（相似块变多、噪音天花板抬高）它会误杀三成。**阈值是数据分布的一次快照，语料一变就失效。**
  - **关键词路**：正样本 0.692…0.062；负样本 0.333…0.000 → 重叠区 [0.062, 0.333]；0.15 那一档误杀 11 (50%) / 漏放 6 (27%)。两路量级完全不同 → 「量纲不可跨路搬运」从道理变成两张分布表。
- **镜 3 · query 自足性（决定性，回答第 8 课悬案）**：5 道追问，**A 原话 2/5 ｜ B flash 改写 5/5 ｜ C 人工自足 5/5**。真调模型改写，原样打印：
  - 「那要是再贵一点的呢」原话 top-1 = C02 ❌ → 改写「报销单金额更高时需要谁审批」→ ✅C15
  - 「那要是没来得及用呢」❌C01 → 「调休没来得及用怎么办」→ ✅C10
  - 「那最早能定到什么时候」❌C06 → 「会议室最早可以预约到什么时间」→ ✅C29
  - **诚实发现（写进课件）**：第 2 行的改写「住院费用中不能报销的部分怎么处理」**把意思理解偏了**（原追问指的是门诊），只因"住院"这个主题词还在就照样捞对 —— **命中 ≠ 改写正确**，改写质量仍要人看。
- **镜 4 · top_k 扫描**：Hit@k 在 k=2 即到 1.00、Recall@k 在 k=3 到 1.00；其后 k=5/8 指标纹丝不动，平均注入 token 91 → 197 → 302 → 466；**全量塞 30 块 = 1576 token，是 k=3 的 8.0 倍而指标一个点没涨**（第 8 课"为什么不全塞"的量化收尾）。
- **教师出题时真踩的坑（已写进课件，作为"评估集要评审"的实例）**：初版有一题「凌晨一点收工打车回家，这笔钱能报吗？」标 gold = C03（市内交通），**三路全"错"**——都指向 C12 加班夜间打车。查语料：C12 明写"加班到 21:00 之后打车可报销"。**不是检索器坏了，是 gold 标错了**；已把该题改成只属于 C03 的问法（台风天打车见客户）。教学点：**指标异常时先怀疑题，再怀疑检索器。**
- **尺子自身的分辨率（写进课件诚实提醒）**：22 题上名次差一名 = 4.5% → "混合·语义×2 的 0.95" 与 "混合 0.91" 之间只差**一道题**，该量级差距**不足以**下结论；且题与语料皆由教师自撰、偏乐观 → 生产须持续扩题 + 留验收集。
