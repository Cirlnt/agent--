Agent 怎么记得住？
（多轮状态与上下文管理）

前六课你的 Agent 每次只答一个问题就退出——因为它天生就是这样：模型是无状态函数，上一次对话一个字都留不下。今天把三件事讲透：Agent 的"记忆"到底存在哪、怎么让它真·多轮对话还不断片、对话太长后怎么用截断 / 滑动窗口 / 滚动摘要三招管住——这正是第 6 课那句"别让对话无限长"的实现课。

使命：3 个月转 AI 应用工程师 约 60–80 分钟 需要：第 6 课跑通的环境（venv + 环境变量） 花费：几分钱 token

面试官爱问一句："上次聊到一半用户走了，回来你的 Agent 还记得刚才的事吗？怎么做的？" 新手会答"给模型加个记忆"；老手会先纠正提问里的错觉——模型没有记忆可加，它每轮都是白纸一张； Agent 能"记住"，唯一原因是你每轮把历史原样喂回去。所以真正的问题是： "你（应用层）把什么喂回去了、喂不下的怎么办？" 本课就用实验把这条机制和它的取舍量给你看。

1 · 心智模型：记忆不在模型里，在你喂回去的历史里

模型无状态：它不记得你，靠的是你"拍档案"

第 6 课立过这条：模型是无状态函数，每次调用它只能看到你这次发过去的内容。 把这句话换到"记忆"视角：Agent 的短期记忆 = 当前上下文窗口里，你塞进去的全部历史。 它会"记得你上次说什么"，不是因为脑子里存了，而是因为那轮对话的文字还在 messages 里、又被你发了一遍。 

第 1 问：你发  [system+工具] + [用户：查上海天气]  → 模型答"上海 多云23°C"
         你把 这轮一问一答 存进 messages
第 2 问：你发  [system+工具] + [上海那轮] + [用户：那北京呢？]  → 模型看到上海那轮，才懂"呢"指天气
         你把 这轮一问一答 也存进 messages
第 3 问：你发  [system+工具] + [前两轮] + [用户：我第一次问的哪个城市？] → 答"上海"

这段对话每轮的"记忆"，全都在 messages 里、由你维护。模型那边零存储。 本课镜 1 会做个决定性对照：同样问"我第一次问的哪个城市"，带历史答得出来，冷启动（零历史）只能承认不知道。

新手第一坑：多轮"断片"几乎都是因为你少存了一边

让它多轮记住，代码只要求两件事：① 每轮把用户的话 append 进 messages；② 每轮也把模型（助手）的答复 append 进去。 很多人只做①不做② → 下一轮模型看不到它自己上次说过什么，历史也常因 user/user 连发被 API 拒收（400）。 记住这句：messages 是一问一答成对长的，漏了 assistant 那半，对话当场断片。（挑战 A 让你亲手补这一半。）

记忆分两层看：窗口里"现成"的，和窗口外"存着"的

做 Agent 时把"记忆"拆成两层，思路会特别清楚：

  • ① 短期记忆 = 上下文窗口：就是 system + 工具 + 历史，每轮随请求整段送进去。第 5 课以前你写的循环、镜 1 的多轮对话都只在这层。
  • ② 长期记忆 = 你自己存出去的东西：文件 / 数据库 / 向量库（RAG）——模型自己不碰它，需要时由你检索最相关几段再喂进来。本课只立概念、指路；下一课（M3 第二课）动手做 RAG。
一句话记忆

Agent 没有记忆，只有"你每轮喂回去的历史"。它"记得"= 历史还在输入里；多轮不断链 = 你原样喂回； 历史太长会越聊越贵（第 6 课）甚至坏掉 → 就得管历史。想要"记得更久又不多烧钱"，出路不是把历史喂全， 而是只喂相关的——那是检索注入（RAG），下一课。

上下文窗口是"稀缺预算"：越长 ≠ 越聪明

窗口不是无限大的。就算不撞 400，长到一定程度模型的表现也会悄悄下降——Anthropic 实测在文档里找信息： 8k token 内找回率 95%+，32k 掉到 ~78%，到 100k 时约三成关键信息会漏（"context rot / lost in the middle"）。 所以别天真地"把窗口买大就完事"，而是像管理内存一样管理放进窗口的东西。 第 6 课讲成本时你已经为"别让对话无限长"埋了钩子——今天的三招就是那根钩子的实现。

三招管长对话：截断 / 滑动窗口 / 滚动摘要

策略 做法 记住的 丢掉的 额外代价
全留 keep-all 什么都不做，历史无限堆 全部 ✅ 无 每轮只涨不跌，迟早撞上限 / 越聊越贵
滑动窗口 只留最近 N 轮，老的整段裁掉 最近 N 轮 N 轮之前的全部 无（最省）
滚动摘要 老历史压成一段摘要，留最近几轮原文 "要义" 细节、数字可能被压丢 每压一次花一次模型调用；压缩器会"自作主张"

三招没有谁"全对"——它们各自用"丢一点东西"换"预算封顶"。真正的问题永远是你愿意丢哪部分。

本课一句话核心（请记到能默写）

记忆 = 你每轮喂回去的历史；历史无限长不可取 → 三招管理：截断 / 滑动窗口 / 滚动摘要。 全留记得全但越聊越贵；窗口封顶最省但整段失忆；摘要封顶又留住要义，可它每次压缩都要花一次模型调用、还会丢细节。 面试答"怎么给 Agent 加记忆"——先答无状态 + 历史喂回，再答这三招的取舍，就比说"我用向量库"高一档（向量库是下一课的工具，不是本课的答案）。

挑战 A（必做，约 15 分钟）· 把 0001 从"答一句就退出"改成真·多轮 REPL

打开 code/0001-minimal-agent.py（第 6 课成品态：流式 + SYSTEM_SCOPED + 出口 + 账单仪表盘都在）。把 从 # --- 3) 对话历史从这里开始 --- 到文件末尾整段替换成下面这段（上面 MODEL/价格/工具/SYSTEM 一行不动）：

# --- 3) 对话历史从这里开始（★ 多轮版） ---
# 只改两处：(1) 每轮把模型答复【记回 messages】(2) 外层循环读输入（REPL）
messages = []          # 记录层：一问一答的纯文本（成对），工具往返不常驻

def answer(user_text: str):
    """处理用户一句话。agentic loop 在局部 working 跑完；结束只把问/答文本写回 messages。"""
    working = list(messages) + [{"role": "user", "content": user_text}]
    while True:
        with client.messages.stream(model=MODEL, max_tokens=4096, tools=TOOLS,
                                    messages=working, system=SYSTEM_SCOPED) as s:
            for chunk in s.text_stream:            # 逐字蹦（第 5 课）
                print(chunk, end="", flush=True)
            response = s.get_final_message()
            u = response.usage
            print(f"\n[账单] 本轮 input={u.input_tokens} 命中缓存={u.cache_read_input_tokens or 0} "
                  f"output={u.output_tokens}  ≈ {u.input_tokens/1e6*INPUT_PRICE_PER_M + u.output_tokens/1e6*OUTPUT_PRICE_PER_M:.4f} 元")

        if response.stop_reason == "tool_use":
            results, exit_payload = [], None
            for block in response.content:
                if block.type != "tool_use":
                    continue
                print(f"[工具请求] 模型想调用: {block.name}({block.input})")
                if block.name == "report_weather":
                    exit_payload = block.input          # 出口工具：答案在参数里
                    continue
                elif block.name == "get_weather" and block.input.get("city") not in SUPPORTED:
                    output = f"错误：暂不支持城市 {block.input.get('city')}。支持：{SUPPORTED}"
                else:
                    output = EXEC[block.name](**block.input)
                results.append({"type": "tool_result", "tool_use_id": block.id, "content": output})
            if exit_payload is not None:
                print("✅ 结构化最终输出：", exit_payload)
                messages.append({"role": "user", "content": user_text})
                messages.append({"role": "assistant",
                                 "content": f"{exit_payload['city']} 当前天气：{exit_payload['condition']}"})
                return
            working.append({"role": "assistant", "content": response.content})
            working.append({"role": "user", "content": results})
            continue

        final = "".join(b.text for b in response.content if b.type == "text")
        if response.stop_reason != "end_turn":
            print(f"! 意外停止：{response.stop_reason}")
        messages.append({"role": "user", "content": user_text})   # ★ 记用户的话
        messages.append({"role": "assistant", "content": final})  # ★ 记模型的答复——漏了这句就断片
        return

# --- 4) ★ 真·多轮 REPL ---
print("多轮天气助手（支持：北京/上海/巴黎/纽约 天气、当前时间；输入 exit 退出）")
while True:
    q = input("\n你: ").strip()
    if q.lower() in ("exit", "quit", "q", "退出"):
        break
    if not q:
        continue
    answer(q)

自我解释练习（最重要的 3 分钟）

合上代码，用你自己的话讲给空气（或发给老师我）：

它们的共同代价是____；其中滚动摘要还要额外付____（每次压缩一次模型调用），而且____保住多少要看压缩器。
